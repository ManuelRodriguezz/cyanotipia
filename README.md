# cyanotipia — E-commerce de Moda & Belleza

Stack: Next.js 16, React 19, Tailwind CSS v4, Framer Motion, Zustand, Mercado Pago API.

## Variables de entorno

Crear un archivo `.env.local` con:

```
MP_ACCESS_TOKEN=tu_access_token_de_mercado_pago
NEXT_PUBLIC_BASE_URL=https://tu-dominio.vercel.app
```

## Deploy en Vercel

1. Subir el proyecto a GitHub
2. Importar en vercel.com
3. Configurar las variables de entorno arriba
4. Deploy automático

## Desarrollo local

```bash
npm install
npm run dev
```
